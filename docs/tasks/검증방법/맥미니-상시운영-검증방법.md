# 맥미니 상시 운영 — 검증방법

art-galleries 를 맥미니에서 pdfsnap 과 동일한 방식(GitHub Actions self-hosted runner →
Docker nginx 컨테이너 → 공용 Cloudflare Tunnel)으로 상시 운영하는 구성의 검증 절차.
(nginx 컨테이너 내부 수신 포트: **3100**. Cloudflare Public Hostname 은 `art-galleries-frontend:3100`.)

> 운영 명령은 맥미니(배포 호스트)에서 실행한다. 외부 접속 검증(F)은 어느 OS에서나 가능하다.

---

## A. 컨테이너 가동 확인 (mac/linux)
```bash
docker ps --filter name=art-galleries-frontend --format '{{.Names}} {{.Status}}'
```
기대: `art-galleries-frontend Up ...` 출력.

## B. edge_shared 네트워크 합류 확인 (mac/linux)
```bash
docker network inspect edge_shared --format '{{range .Containers}}{{.Name}} {{end}}'
```
기대: 출력에 `art-galleries-frontend` 와 공용 `cloudflared` 가 함께 포함.

## C. 컨테이너 내부 헬스/라우팅 확인 (mac/linux)
```bash
docker exec art-galleries-frontend wget -qO- http://127.0.0.1:3100/healthz          # → ok
docker exec art-galleries-frontend wget -qS  -O /dev/null http://127.0.0.1:3100/ 2>&1 | grep HTTP            # → 200, 301 아님
docker exec art-galleries-frontend wget -qS  -O /dev/null http://127.0.0.1:3100/chicago-museum 2>&1 | grep HTTP        # → 200
docker exec art-galleries-frontend wget -qS  -O /dev/null http://127.0.0.1:3100/chicago-museum/search 2>&1 | grep HTTP # → 200
```
기대: 모두 `HTTP/1.1 200`. `/chicago-museum` 이 301(트레일링 슬래시 리다이렉트)이면 안 됨.

## D. self-hosted runner 확인 (mac/linux)
```bash
launchctl list | grep art-galleries          # 서비스 로드 확인 (PID 또는 0)
```
GitHub: 레포 → Settings → Actions → Runners 에 `kyle-mini-art-galleries` 가 **Idle** 로 표시.

## E. 자동 배포(CD) 동작 확인
1. `main` 에 더미 커밋 push (예: README 한 줄).
2. GitHub → Actions → "Deploy to art-galleries.kr" 워크플로가 **success(green)**.
3. 로그에 `HEAD: <before> → <after>` 와 `healthy at attempt N`, `deploy OK` 출력 확인.

## F. 외부 공개 접속 확인 (win/mac/linux — Cloudflare Public Hostname 설정 후)
- mac/linux:
  ```bash
  curl -I https://art-galleries.kr/                 # → HTTP/2 200
  curl -s  https://art-galleries.kr/ | grep -i '<title'   # 허브 페이지 타이틀 확인
  curl -I https://art-galleries.kr/chicago-museum   # → 200
  ```
- windows (PowerShell):
  ```powershell
  (Invoke-WebRequest https://art-galleries.kr/ -Method Head).StatusCode          # → 200
  (Invoke-WebRequest https://art-galleries.kr/chicago-museum -Method Head).StatusCode  # → 200
  ```
- 브라우저: `https://art-galleries.kr/` 접속 → 허브에서 각 박물관(chicago/metropolitan/cleveland/vna-east) 이동 정상.

---

## 통과 기준
A~E 가 맥미니에서 모두 통과하고, Cloudflare Public Hostname 설정 후 F 가 통과하면 상시 운영 구성 완료.
